# Xiolaet — pre-launch landing page

A single-page, static HTML/CSS landing site. No build, npm, framework, or external assets.

## View locally

From this directory run:

```bash
python3 -m http.server 8000
```

Open http://localhost:8000/ in a browser.

## Publish to xiolaet.com with GitHub Pages

1. Upload `index.html`, `favicon.svg`, `robots.txt`, `sitemap.xml`, and `assets/` to the selected repository root.
2. In repository Settings > Pages, deploy from the root branch folder.
3. Configure custom domain `xiolaet.com` in GitHub Pages and set correct DNS records at the domain registrar, following GitHub's current official documentation.
4. Enable HTTPS when GitHub Pages offers it.
5. Verify https://xiolaet.com/ and the outbound social links.
6. The domain-specific canonical URL, Open Graph URL and image, schema.org URL, and sitemap URLs are preconfigured for **https://xiolaet.com/**. If using any other domain before launch, update them first.

## Social profiles

The live page links only to confirmed YouTube (`@xiolaet`) and TikTok (`@xiolaet_music`). Add Instagram and Pinterest when the exact owned addresses are confirmed. Do not guess links.
